# Dossier de sources — Exploitation & R&D

Consultation : 29 octobre 2026. Les pages ci-dessous ont été trouvées par deux recherches spécialisées comportant plusieurs formulations, puis ouvertes et consultées. Les angles pratiques de la série sont des propositions éditoriales ; les références étayent les éléments techniques ou juridiques indiqués, sans valider une performance universelle.

## Sources lues

Complément de relecture : [Custom instructions for GitHub Copilot](https://docs.github.com/en/copilot/concepts/prompting-and-context/custom-instructions), GitHub Docs, Tier 1, page ouverte le 29 octobre 2026. Les types d'instructions et leur prise en charge varient selon le client et la surface ; leur interprétation reste non déterministe. Cette source complète l'article sur la portabilité, aux côtés d'OpenAI, Claude Code et OWASP ; elle ne démontre pas un comportement identique entre produits.

## Limites et cas sensibles

Les exemples de workflow sont explicitement fictifs et ne constituent ni un résultat client, ni une expérimentation exécutée. Les recommandations produit sont attribuées à leur éditeur. Le sujet d’analytique du travail ne formule aucun avis légal individualisé : la CNIL indique que le contrôle peut être autorisé sous conditions cumulatives, notamment justification/proportionnalité, information et consultation lorsque requise ; une agrégation n’efface pas automatiquement les questions de données personnelles. Les seuils de réussite proposés sont des critères d’acceptation à définir localement, pas des benchmarks publiés.
