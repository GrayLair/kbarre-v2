# Technical Spike

Use when a concrete question must be answered before committing to a design or estimate.
Define a narrow question, a time or effort bound if supplied, hypotheses, available
evidence, investigation steps, success criteria, and the decision the result will enable.

Report findings separately from assumptions, include reproducible experiments or sources,
and end with a recommendation and remaining unknowns. Avoid turning a spike into an
unbounded research project or implementing production changes unless requested.
