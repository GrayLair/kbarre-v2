# Architecture Decision Record

Use when a decision has durable impact on architecture, interfaces, operations, security,
or team workflow. Do not use for an implementation note with no meaningful alternative.

Follow the repository's ADR convention when it exists. Otherwise include: title and
status, context and constraints, decision, alternatives considered, positive and negative
consequences, migration or rollout notes when needed, and links to supporting evidence.
State uncertainty clearly. Do not claim consensus or approval that has not occurred.
