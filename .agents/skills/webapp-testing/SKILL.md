# Web Application Testing

Use for UI regressions, end-to-end flows, browser-visible behavior, console errors, and
accessibility checks. Confirm the project’s test tooling and whether the app can be run
locally before acting.

Prefer existing browser tests and configured MCP tools. If tooling is missing, report the
prerequisite and ask before installing packages or browsers. Capture concise reproduction
steps and only the evidence needed to diagnose the issue: assertions, screenshots,
console messages, or network failures. Do not change application code unless requested.
