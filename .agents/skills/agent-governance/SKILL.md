# Agent Governance

Use only for systems that implement AI agents or tool-using models. Map authority,
identities, data classification, tool permissions, approval gates, audit trails, and
failure handling. Consider prompt injection and confused-deputy risks at every boundary.

Recommend the least complex controls that materially reduce demonstrated risk. Preserve
human approval for consequential external actions unless the user specifies a justified
automation policy. Do not impose a framework, policy engine, or compliance regime without
a concrete requirement.
